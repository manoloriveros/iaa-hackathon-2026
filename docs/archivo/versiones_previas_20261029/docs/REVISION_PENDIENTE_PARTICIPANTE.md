Para cada código, indica tu decisión, el motivo y la evidencia que leíste. Puedes usar «aceptar el alcance del concurso», «pedir una corrección concreta» o «mantener abierto» cuando corresponda. No hace falta que afirmes resuelta una incertidumbre que los datos no pueden resolver.

La aprobación general requiere tu respuesta real, fecha y alcance en [revision_humana.json](../../../../registro/revision_humana.json). Las notas del navegador y esta plantilla no completan esos campos automáticamente. Las decisiones específicas anteriores se conservan.
