## Lectura del proyecto

La sugerencia del cuaderno de Kaggle responde a un equipo cuyo Git interno no puede compartirse con externos. El requisito de fondo es una base de código reproducible para los archivos de predicciones, alcanzable por el jurado desde la URL del formulario. Un repositorio de GitHub cumple si el jurado puede abrirlo; el cuaderno de Kaggle es una copia alternativa que, además, permite ejecutar el código sobre los datos del concurso sin redistribuirlos.
